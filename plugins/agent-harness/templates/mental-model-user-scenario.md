# User / Scenario Model

## Adoption

- New project: initialize adapter, install skills, run doctor.
- Existing project: preserve its task index, import config, preview before writes.
- Accepted Goal: deliver and verify in the host, then synchronize outcome state.

## Division

- Human: product direction, constraints, authorization and true decisions.
- Host: session, resume, workers, transient plan, execution and full logs.
- Harness: target, dependencies, concise verification and bounded state.

## Continuation

Resume with the host session. Do not reconstruct execution history from Run
artifacts. Read only the accepted Goal, remaining gaps and current status.
