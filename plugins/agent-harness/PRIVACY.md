# Privacy

Agent Harness is local software. The plugin does not operate a service, and it
does not send telemetry or collect personal data for the maintainers.

Commands and skills read and write files in the project you choose to run them
in. Those files stay in that project.

The public source repository is hosted on GitHub. GitHub's privacy statement
applies to that hosting:
<https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement>
