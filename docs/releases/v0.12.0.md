# Agent Harness v0.12.0

Release preparation started: 2026-09-16

This version has not been published as a Git tag or GitHub Release. Local
release metadata remains preparation evidence until the separately authorized
push and release step is complete.

## Summary

Agent Harness keeps one model-neutral execution contract. Older models can use
the current session and a short checklist; newer hosts may use runtime outcome,
transient plan, delegation, isolation, and result-packet capabilities when the
host exposes them.

## Compatibility Contract

- Capabilities are detected from the current host, never inferred from a model
  name.
- Missing capabilities fall back to the current session without imitation
  runtime artifacts or invented runtime identifiers.
- Deterministic CLI validation remains responsible for path, manifest, gate,
  evidence, and accepted-state checks.
- Prepared enforced Runs retain repository-level recovery and evidence
  requirements across model and host changes.
