# Agent Harness v0.11.0

Release preparation started: 2026-09-16

This version has not been published as a Git tag or GitHub Release. The
repository remains under local release preparation until a separately
authorized release assigns it to a tag.

## Summary

Agent Harness now has one model-neutral execution contract. Older models can
use the current thread and a short checklist; newer Codex runtimes may use
native Goal, Plan, subagent, or steering capabilities when those capabilities
are actually exposed by the host.

## Compatibility Contract

- Runtime capabilities are detected from the current host, never inferred from
  a model name.
- Missing native capabilities fall back to the current thread without creating
  imitation runtime artifacts or inventing runtime identifiers.
- Deterministic CLI validation remains responsible for path, manifest, gate,
  evidence, and accepted-state checks.
- Prepared enforced Runs retain their repository-level recovery and evidence
  requirements across model and runtime changes.

## Verification

The release gate requires:

```bash
npm run test:all
npm run test:eval
npm run validate:plugin
```

These checks cover version alignment, generated Goal compatibility, direct and
durable routing, legacy artifact handling, containment, lifecycle behavior,
and plugin structure.
