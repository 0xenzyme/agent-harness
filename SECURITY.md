# Security Policy

## Supported versions

Security fixes land on the default branch for the latest release. The current
release is 0.13.0. Older releases are not maintained on separate security
branches.

## Reporting a vulnerability

Agent Harness runs locally in the project you choose. It does not operate a
hosted service.

Report suspected vulnerabilities through GitHub private vulnerability reporting:

<https://github.com/0xenzyme/agent-harness/security/advisories/new>

Include the affected version, the impact, and a reproduction when you have one.
Do not open a public issue that contains exploit details.

The installable plugin package carries the same policy at
`plugins/agent-harness/SECURITY.md`.
