# User / Scenario Model

## Adoption

Initialize or import the adapter, install skills, and run `doctor`. Preserve
existing task indexes and project instructions. Activation preview does not
modify `AGENTS.md`.

## Delivery

The human sets direction and authority. The host executes and resumes through
its session/history. Harness tracks the accepted Goal/Milestone, verification
summary and bounded state. No Run or execution receipt is needed.

## Continuation

Read the target and remaining gaps, then continue in the host. New source
changes are verified directly. They do not invalidate historical completion.

## Boundaries

Pause for unclear product direction, missing authority, credentials, paid API,
production/destructive action, or failed required verification. Do not pause
for code drift or missing execution archaeology.
